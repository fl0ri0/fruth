Truth

  • outputs[] is the public output contract; durable completion needs verified persisted frame and artifact evidence.
  • Artifact dossiers are keyed by artifact_ref.
  • Assistant text alone is not canonical payload truth.

Interpretive inference

  • The interpretive inference layer derives and orients current-turn semantics.
  • decision_contract and semantic roles are advisory.
  • No Deliberation subsystem is current architecture.

Work

  • working_frame is mutable live request state.
  • A runtime-owned, authoritative work_tree is internal work truth.
  • output_slots are projections of work truth.

Closure

  • Runtime Closure checks evidence before freeze. A frozen frame may still record blocked or incomplete work.
  • Late fill continues anchored promoted obligations.
  • Repair must not invent fresh user intent.

Persistence

  • Artifact registration, Ledger/CAS/Index persistence, and client delivery are distinct boundaries.
  • Ordinary persistence errors are currently logged; a returned completed payload is not a commit receipt.
  • Readiness evidence does not grant rebase operator authority.
